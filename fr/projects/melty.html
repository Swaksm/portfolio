MELTY.

SENTINEL-X, un projet d'équipe pour un workshop EPSI : un ESP32 surveille une table, une IA apprend ce qui est normal, une webcam repère les personnes, et l'équipe est prévenue par buzzer, mail et dashboard en direct.

Le sujet

Un workshop EPSI Bac+4 sur un client fictif, AetherCorp. Le sujet imposait : pas de seuils statiques, des flux chiffrés, une stack conteneurisée et aucun secret dans l'archive du code. Réalisé en équipe de trois.

Comment ça marche

  • Un ESP32 (DHT22, capteur de gaz MQ-2, PIR, écran OLED, buzzer) envoie température, humidité et gaz en MQTT/TLS à un broker Mosquitto ; un backend FastAPI les enregistre dans PostgreSQL.
  • Aucun seuil écrit à la main : un modèle Local Outlier Factor apprend, table par table, à quoi ressemble une période calme (5 valeurs sur les 30 dernières mesures, dont la tendance de la température et du gaz) et signale ce qui s'en écarte. Sur données simulées, il détectait 100 % des pics avec 0,5 % de fausses alertes, contre 94 % et 6,8 % pour Isolation Forest.
  • Un second modèle, un Random Forest, surveille uniquement la tendance de la température pour repérer une montée lente.
  • Une webcam fait tourner YOLOv8 nano : une personne doit rester visible 3 secondes pour déclencher une alerte ; les animaux sont encadrés mais ignorés. Environ 13 à 15 images par seconde sur le processeur d'un portable.
  • Les alertes font sonner le buzzer et envoient au plus un mail par type toutes les 5 minutes, avec une capture. Le dashboard React affiche un bandeau rouge, et chaque alerte nomme la mesure la plus responsable.

Sécurité

  • Depuis le Wi-Fi, seuls deux ports sont joignables, tous deux chiffrés : MQTT en TLS mutuel pour l'ESP32, et HTTPS via un proxy Caddy pour le dashboard, l'API et la vidéo.
  • Le HTTPS n'accepte que les 5 postes autorisés (certificats clients), puis exige une connexion (JWT en cookie HttpOnly, protection contre la force brute).
  • Un compte MQTT par composant, limité à ses propres sujets.

Sous le capot

Firmware C++ (Arduino, mises à jour OTA), Python 3.12, FastAPI, SQLAlchemy, scikit-learn, Ultralytics YOLOv8 et OpenCV, React 18 + Vite + Recharts, PostgreSQL 16, le tout en Docker Compose avec cAdvisor pour la supervision. pytest et GitHub Actions à chaque push, images publiées sur GHCR.
